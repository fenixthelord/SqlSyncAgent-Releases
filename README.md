## ما هو Cliprz Agent؟

برنامج صغير يعمل بهدوء على حاسوب المحل (Windows)، ويقرأ بيانات برنامجك المحاسبي ويرسلها إلى متجرك على [Cliprz](https://cliprz.net)، فتبقى منتجاتك وأسعارك وكمياتك في المتجر محدّثة دون إدخال يدوي.

**برنامج المحاسبة يبقى هو المصدر الأساسي لبياناتك. الوكيل يقرأ فقط ولا يعدّل شيئاً في قاعدة بياناتك.**

## الميزات

| | |
|---|---|
| 🔄 **مزامنة تلقائية** | يرسل الجديد والمعدّل والمحذوف فقط، ولا يعيد إرسال ما لم يتغيّر. |
| 🧾 **برامج محاسبة مدعومة** | الكثير من البرامج المدعومة مع إعدادات جاهزة تُكتشف تلقائياً، إضافة إلى الربط اليدوي للجداول والأعمدة. |
| 🧩 **برنامج محاسبة خاص** | اربط ملف قاعدة بيانات **SQLite** لبرنامجك الخاص من قائمة «Custom accounting program». تُقرأ البيانات للقراءة فقط. |
| 💱 **العملات والأسعار** | مزامنة العملات وأسعار المنتجات المتعددة (مفرق، جملة، نصف جملة، تصدير، موزّع). |
| 🔒 **قراءة فقط** | لا يكتب في قاعدة بيانات برنامجك المحاسبي. |
| 🛡️ **تحديثات موقّعة رقمياً** | لا يثبّت الوكيل أي تحديث قبل التحقق من توقيع Cliprz عليه. |
| 🌐 **اتصال آمن** | كل الاتصال بين الوكيل ومتجرك عبر HTTPS. |
| 🙈 **حماية أسعار التكلفة** | لا تظهر أسعار التكلفة لزبائن متجرك. |
| 🧹 **سجلات خاصة** | تُحذف السجلات الفنية تلقائياً بعد 14 يوماً ويُحجب منها اسم المستخدم. |
| 🗣️ **واجهة عربية** | واجهة عربية كاملة بتخطيط من اليمين إلى اليسار، ويعمل من أيقونة الـ tray بجانب الساعة. |

## التثبيت

1. حمّل [`SqlSyncAgent-Setup.exe`](https://github.com/fenixthelord/SqlSyncAgent-Releases/releases/latest/download/SqlSyncAgent-Setup.exe).
2. شغّل الملف واتبع المعالج. التثبيت لا يحتاج تثبيت .NET على الحاسوب.
3. افتح البرنامج، وأقرّ اتفاقية الاستخدام، ثم اربطه بمتجرك من لوحة تحكم Cliprz.
4. اختر قاعدة بيانات برنامج المحاسبة، وسيبدأ المزامنة تلقائياً.

عند التحديث، تبقى إعداداتك وبيانات الربط وسجل المزامنة كما هي.

## التحديث

يتحقق الوكيل من وجود إصدار جديد ويعرض زر التحديث داخل البرنامج. التحديث يتم بعد التحقق من التوقيع الرقمي، ويمكنك أيضاً تحميل أي إصدار يدوياً من [صفحة الإصدارات](https://github.com/fenixthelord/SqlSyncAgent-Releases/releases).

## المتطلبات

- Windows 10 أو أحدث (64-bit).
- برنامج محاسبة مبني على (SQL Server)، أو ملف SQLite لبرنامج خاص.
- متجر على [Cliprz](https://cliprz.net).
